# 도메인 역할 및 담당자

각 도메인이 담당하는 기능과 담당자를 정리한 문서입니다.

| 도메인 | 역할 | 담당자 |
| --- | --- | --- |
| `/auths` | 로그인 및 회원가입 등 사용자 인증을 담당합니다. | 민수 |
| `/trades` | 매수·매도 로직을 담당합니다. Toss API를 연동하고 조건부 매수·매도 주문 기능을 제공합니다. | 동현 |
| `/markets` | 종목 조회와 종목 숨기기 관련 비즈니스 로직을 담당합니다. | 태하 |
| `/assets` | 사용자의 자산 현황 조회와 자산 숨기기 관련 비즈니스 로직을 담당합니다. | 현진 |
| `/users` | 사용자 정보와 숨긴 종목 및 관심 종목을 관리합니다. | 현진 |
| `/diaries` | 사용자의 투자 일지 작성, 조회, 수정 및 삭제를 담당합니다. | 건우 |
| `/ai-chat` | AI 기반 채팅 기능을 담당합니다. | 건우 |

> 현재 소스 디렉터리 이름은 `auth`이지만, 이 문서에서는 요청된 API 경로인 `/auths`로 표기했습니다.
